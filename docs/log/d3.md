## 踩到的坑（写代码时留下的）

| 现象 | 判断 | 处理 |
|---|---|---|
| `join()` 抛 `TypeError: 'Event' object is not callable` | 采样线程属性取名 `self._stop`，覆盖了 `threading.Thread` 自带的 `_stop()` | 改名 `_stop_evt`；Thread 子类属性一律避开基类私有方法名 |
| 客户端 `decode_tps` 比服务端 `srv_tg` 稳定高约 10% | SSE 分片被 TCP 缓冲，首片到达偏晚，`(t_last - t_first)` 被压短 | 锚点判定只用 `srv_tg`/`srv_pp`；客户端列只回答"体感速度" |
| 第 2、3 次请求莫名变快 | prompt cache 命中 | 每条请求前加随机 nonce，废掉前缀缓存 |
