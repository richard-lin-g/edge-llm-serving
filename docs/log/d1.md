# D1 日志 · 2026-11-09（周一）

设备：台式机 · Windows 11 + NVIDIA T600（4096 MiB，驱动 572.83，CUDA 12.8）｜WSL2 / Ubuntu｜投入约 5h（下午开工）

## 做了什么

1. 记录硬件基线：T600 4096 MiB、compute capability 7.5、空闲基线 678–865 MiB（Xwayland 占用）
2. WSL2 + Ubuntu 装通，`nvcc` 12.6 经 `~/.profile` 生效，WSL 内 `nvidia-smi` 能看到卡
3. 编译 llama.cpp：首版漏编 CUDA（nvcc 当时不在 PATH，CMake 静默退化为 CPU-only），用 `ldd` 查出来后 `rm -rf build` 重配 `-DGGML_CUDA=ON -DCMAKE_CUDA_ARCHITECTURES=75` 重编成功，版本 b12033-785322d17
4. 下载 3B Q4_K_M（2 104 932 768 B，与官方一致），跑 GPU / CPU 两组冒烟

## 卡在哪 / 怎么解决

| 现象 | 判断 | 处理 | 是否解决 |
|---|---|---|---|
| `nvcc -V` 报 command not found，但 apt 显示 cuda-toolkit 已装 | 文件在 `/usr/local/cuda-12.6/bin`，只是 PATH 未生效 | 写 `~/.profile`（不是只写 `.bashrc`），新会话验证 | 是 |
| `build/` 存在但 `ldd` 看不到 libcuda / libcublas | CMake 找不到 nvcc 时静默退化 CPU-only，不报错 | 删 `build` 重配，显式 `-DGGML_CUDA=ON -DCMAKE_CUDA_ARCHITECTURES=75` | 是 |
| `~/models` 里有 0 字节的 7B gguf、分卷大小与官方不符 | 下载中断 / 下到错误页（curl 不带 -f 时不报错） | 记录待重下，D2 处理（今天用不到 7B） | 待处理 |
