## 今日结论

- 本机最优 `-ngl` = **36（全量）**，tg 39.33 t/s，纯 CPU 21.71 → **1.81×**。与 D1 的 40.0（`-n 64` 口径）差 1.7%，两个数可互相印证。
- 曲线非线性：0→10 只 +4.7%，10→20 却 +39.4%。推测是每次 token 的 CPU↔GPU 同步开销固定，GPU 份额小时盖不住；用 `-ngl 12/16` 定位拐点。
- pp 六档只从 139.87 涨到 152.14（+8.8%）：prefill 是算力活且 CPU 侧已接近饱和，加 GPU 主要救的是 decode。
- 32 与 36 只差 4.2%，但省 4 层约 222 MiB；而 KV 从 ctx4096 到 8192 只多约 147 MB —— 速度换显存这笔账能直接付掉上下文翻倍（留给 D8）。
- 全量峰值 2787 MiB，余量 1308 MiB。若峰值 > 3000 MiB，D9 并发压测前必须先降档。
