- **深度曲线**（`-d 0/2048/4096/8192`）：
  - pp：152.93 → 120.88 → 102.13 → 78.95 t/s（**−48.4%**）

## 三、卡在哪（写清楚，明天不再重复踩）

1. **`llama-cli` 在 b12033+CUDA13.3+WSL 下无输出**，不要再用它做采集；静态显存一律 `llama-server -np 1`。
2. **`llama-bench` 没有 `-c`**，改用 `-d`；调优脚本里任何残留的 `-c` 都会让整组失败（`d8_tune.sh` 已清掉）。
3. **PowerShell → WSL 内联命令会吃掉 `$VAR` 与内联引号**（`BIN=$HOME/...` 变成 `/...`、`tr -d " "` 参数被拆）。长脚本一律**先写成 `.sh` 文件再 `cp` 进 WSL 执行**，`wsl.exe` 用全路径 `C:\Windows\System32\wsl.exe`。
4. **`-np` 默认是 4**（`n_slots = 4`），会把 `-c` 按槽均分；静态实验必须显式 `-np 1`，否则量到的 KV 只有 1/4，公式必然对不上。
5. **KV 量化的显存收益只能用静态口径量**：用 `-d 8192` 的速度实验口径去读显存，会得到「只省 6 MiB」的假结论（8K prefill 的 compute buffer 把差值淹了）。
